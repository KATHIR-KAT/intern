Welcome to PHP SOCKS5 VPN

A lightweight SOCKS5 proxy with a browser dashboard for starting, stopping and monitoring the local proxy server.

Start Mac Setup →Open Dashboard

Lightweight

Runs directly with PHP and uses non-blocking sockets with stream_select().

SOCKS5

Accepts SOCKS5 CONNECT requests and supports IPv4, IPv6 and domain-name destinations.

Live Monitoring

The dashboard displays server status, active connections, transferred data and live logs.

macOS Ready

Use the setup guide to configure the macOS SOCKS proxy as 127.0.0.1:1080.

How it works

The web dashboard controls the PHP SOCKS5 process. The proxy listens locally on port 1080, and macOS applications configured to use that SOCKS5 proxy send their traffic through it.

UI demo only — buttons and connection activity are simulated. No proxy server is started by these static files.
