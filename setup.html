 macOS Setup

Follow these steps to run the dashboard and configure the built-in macOS SOCKS proxy.

1

Check PHP

Open Terminal and verify PHP is installed.

php -v
2

Open the project

Move into the folder containing index.php.

cd /path/to/php_socks5_vpn
3

Start the local web dashboard

Run the PHP development server from the project directory.

php -S 127.0.0.1:8001
4

Start the SOCKS5 process

In a separate Terminal window, start your proxy server.

php socks5_server.php

macOS Network Settings

  1. Open System Settings → Network.
  2. Select your active connection, such as Wi-Fi, then click Details….
  3. Open Proxies and enable SOCKS Proxy.
  4. Enter server 127.0.0.1 and port 1080.
  5. Click OK → Apply.

Test the connection

curl --socks5 127.0.0.1:1080 https://example.com -I

Watch the Dashboard's Live Audit Logs while testing.

Important: The current server binds to 127.0.0.1, so it is intended for the same computer. It is not exposed to other devices on your network.
